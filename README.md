# 📱 تطبيق مصروفي (Masrofy) - لإدارة المصروفات الشهرية للأندرويد

تطبيق متكامل وسريع مصمم خصيصاً باللغة العربية لإدارة الميزانية الشهرية وتتبع المصروفات والدخل بسهولة وأمان على أجهزة الأندرويد.

---

## ✨ أهم مميزات التطبيق

1. **📊 بطاقة الرصيد والميزانية التفاعلية:**
   - عرض صافي الرصيد المتبقي للشهر الحالي.
   - إجمالي الدخل وإجمالي المصروفات بلمسة واحدة.
   - شريط تقدم الميزانية الذكي (يتغير لونه وفقاً لنسبة الاستهلاك: أخضر، برتقالي، وأحمر عند تجاوز الميزانية).

2. **💸 تسجيل سهل وسريع للمصروفات والدخل:**
   - التبديل بنقرة واحدة بين المصروف والدخل.
   - إدخال المبلغ وملاحظة اختيارية.
   - تصنيفات ملونة بأيقونات معبرة (طعام ومشروبات، سكن وفواتير، مواصلات، تسوق، صحة، ترفيه، التزامات، تعليم...).
   - اختيار طريقة الدفع (كاش 💵، بطاقة بنكية 💳، محفظة إلكترونية 📱).
   - تواريخ سريعة (اليوم، أمس، أو تاريخ مخصص).

3. **📈 إحصائيات وتقارير متقدمة:**
   - نسبة استهلاك الميزانية ومعدل التوفير الشهري.
   - توزيع المصروفات حسب الفئات مع أشرطة تقدم ونسب مئوية.
   - توزيع المصاريف حسب طرق الدفع.
   - تقييم تلقائي للحالة المالية (ممتاز، تحذير، خطر تجاوز الميزانية).

4. **📋 سجل المعاملات والبحث:**
   - البحث بالاسم أو التصنيف أو الملاحظة أو المبلغ.
   - فلترة حسب نوع المعاملة (الكل / المصروفات فقط / الدخل فقط).
   - إمكانية حذف أي معاملة بسهولة.

5. **⚙️ التخصيص والأمان:**
   - دعم كامل للعملات العربية والعالمية (جنيه مصري ج.م، ريال سعودي ر.س، درهم إماراتي د.إ، دينار كويتي، وغيرها).
   - حفظ كافة البيانات محلياً على هاتفك (Offline First) لضمان الخصوصية التامة دون الحاجة لإنترنت.
   - إمكانية مشاركة تقرير الشهر المالي عبر واتساب أو نسخه.
   - زر لتحميل بيانات تجريبية فورية لتجربة التطبيق، وزر لمسح البيانات عند الرغبة في البدء من الصفر.

## 🚀 طريقة التشغيل على هاتفك الأندرويد

### الخطوة 1: تثبيت تطبيق Expo Go على الموبايل
من متجر Google Play على هاتفك، قم بتنزيل تطبيق **Expo Go** (مجاني).

### الخطوة 2: تشغيل التطبيق من الكمبيوتر
افتح مجلد المشروع واضغط مرتين على الملف:
```bash
run-app.bat
```
أو من موجه الأوامر (Terminal) داخل مجلد `masrofy`:
```bash
npx expo start
```

### الخطوة 3: المعاينة على الهاتف
- سيظهر لك في شاشة الأوامر رمز **QR Code**.
- افتح تطبيق **Expo Go** على هاتفك واختر **Scan QR code** وامسح الرمز.
- سيبدأ التطبيق بالعمل فوراً على هاتفك بكل سلاسة!

## 📦 استخراج ملف التثبيت المباشر (APK) للأندرويد

إذا كنت ترغب في تحويله إلى ملف `APK` مستقل لتثبيته مباشرة بدون Expo Go:
1. قم بإنشاء حساب مجاني على [Expo.dev](https://expo.dev).
2. نفّذ الأمر التالي:
   ```bash
   npx eas build -p android --profile preview
   ```
3. ستحصل على رابط تحميل مباشر لملف `apk` لتثبيته على أي جهاز أندرويد.
